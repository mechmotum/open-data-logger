# Data
This is a collection of all previous experiments done with the datalogger. To add to this, please create a folder with a short but recognisable name and add your .csv files into it. If the experiment is done over multiple sessions, you may choose to either save the files in a single folder or iterate folders for clarity (eg. [projectname]01.csv).

## Analysis
To analyse the data, a python file has been set up in the software directory: analyse.py.
